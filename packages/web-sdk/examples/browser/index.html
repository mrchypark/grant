공동인증서 기반 로컬 검증 페이지

브라우저는 제품형 JS SDK만 사용하고, 로컬 `desktop-agent`가 인증서 탐색과 비밀번호 검증을 처리합니다. 이 예시는 프론트가 최소 입력만 넘기고 나머지 수집 범위를 서버가 결정하는 흐름을 검증하기 위한 디버그 하네스입니다.

설정

`인증서 목록 읽기`는 디버그용입니다. 실제 실행 시 인증서 선택과 비밀번호 입력은 agent의 네이티브 승인 모달에서 처리됩니다.

desktop agent는 loopback CORS origin을 직접 검사하므로, 기본값은 dev proxy 대신 `http://127.0.0.1:8765`에 바로 연결합니다.

gateway 호출은 `Authorization: Bearer ...` 와 `x-organization-id` 헤더가 필요합니다. 로컬 dev stack에서는 TrailBase login 후 받은 token을 넣으시면 됩니다.

`Business No`는 선택 입력입니다. 조직에 이미 연결된 사업자번호가 있으면 비워 둘 수 있고, 아직 연결돼 있지 않거나 인증서에서 읽지 못할 때만 실제 10자리 값을 넣으면 됩니다.
